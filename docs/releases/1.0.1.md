Minecraft 1.21.1 · NeoForge · Requires Botany Pots 1.21.1-21.1.42 or newer.

### Configurable pot balance

- Added a world-specific `botanypotsadditions-server.toml`, automatically synchronized to clients.
- Configure double and quadruple harvest yield, greenhouse growth and yield, and sprinkler yield and growth-speed limits.
- Configure sprinkler water/energy capacities, costs per growth operation, maximum energy input per receive call, and minimum operating charge.
- Set either resource cost to zero to disable that requirement. With energy use disabled, sprinklers use their configured maximum speed.
- Defaults retain the existing balance settings: double/quad output tiers, 1.5× greenhouse/sprinkler yield, 2–5 sprinkler growth operations per game tick, 10,000 FE and 4,000 mB storage, and 10 FE + 1 mB per successful operation.

### Fixes

- Apply configured yield when manually harvesting basic pots, including their extra cells.
- Apply block yield and growth modifiers consistently to extra cells and their growth estimates.
- Allow non-sprinkler hopper pots to continue growing extra cells when the first seed slot is empty.
- Handle zero resource costs, large capacities and insufficient resources safely.
- Preserve full integer resource values in menu synchronization and avoid resource-bar arithmetic overflow.
- Clamp saved FE and water to the configured capacity when loading a pot after a capacity reduction.

### Configuration location

Start a world once to generate `<world>/serverconfig/botanypotsadditions-server.toml`. Stop the world/server before editing, then restart it. Modpacks can place a copy in `defaultconfigs/` to supply defaults for new worlds.

Double/quad yield is spread across the seed slots, so empty slots produce nothing. Family and cell yield settings combine; crop recipes, soil and tools can further affect output. Resource costs apply to each successful growth operation, shared across all cells, not to each harvest. The current sprinkler family uses both FE and water; there is no separate powered-sprinkler tier.

See the README for the complete default configuration and tuning guidance.
